# LUCCO - Online Fashion Store

LUCCO is a modern online fashion shopping application developed using Flutter and Firebase. The application allows users to browse fashion products, manage their shopping cart, maintain a wishlist, place orders, and securely authenticate using Firebase Authentication.

## Installation

Clone the repository

```bash
git clone https://github.com/nowfa-310/lucco-online-fashion-store.git
```

Go to the project directory

```bash
cd lucco-online-fashion-store
```

Install dependencies

```bash
flutter pub get
```

Run the application

```bash
flutter run
```

Build Release APK

```bash
flutter build apk --release
```
